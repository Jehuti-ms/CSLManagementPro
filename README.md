# Service Club Manager

A comprehensive web application for managing service clubs with attendance tracking, project management, and reflection tools.

## 🚀 Features

- **User Authentication** - Secure login for teachers/admins
- **Attendance Tracking** - Excel-style attendance with engagement ratings (1-5)
- **Project Tracker** - Track projects weekly, monthly, and annually
- **Reflections** - Separate areas for student and teacher reflections
- **Admin Panel** - Manage clubs and students
- **Firebase Integration** - Real-time data sync (with mock data fallback)

## 📋 Tech Stack

- HTML5, CSS3, JavaScript (ES6+)
- Firebase (Authentication & Firestore)
- Font Awesome Icons
- LocalStorage (for demo mode)
